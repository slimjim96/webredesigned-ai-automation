# SiteFooter

The navy footer on every page: contact, service area, site links, and the "by Web Redesigned" line.

## Use
- The phone number and email are plain text a person can select, plus links where they work. The number here is a sample (555); the real one comes from the owner.
- Service area lists the four on-site regions and "Remote, anywhere" (positioning). These are also local-SEO signals.
- "by Web Redesigned" appears only here and on the About page (brand spec).
- Links are underlined `on-inverse`; small text is `on-inverse-muted` at 15px.
