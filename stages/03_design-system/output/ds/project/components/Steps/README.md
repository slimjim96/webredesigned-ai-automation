# Steps

A numbered sequence (`<ol>`) for things that really happen in order: how an engagement works, how a tool runs.

## Use
- 3 steps is the norm, 4 at most. Each: an H3 that starts with a verb, one or two sentences.
- Numerals are generated (`01`, `02`, `03` in `sage` mono). Don't type them.
- Stacks on phones; three columns from `bp-md`.

## Don't
- Don't use Steps for a list of features or benefits: order must carry meaning.
