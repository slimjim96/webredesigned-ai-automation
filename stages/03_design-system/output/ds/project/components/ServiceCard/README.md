# ServiceCard

One offer, vertical, or article teaser: icon, H3, two-line description, one link.

## Use
- In a `th-card-grid` (auto-fits 280px columns). Use 3 cards for the offer ladder, 3 for the verticals. Never 2 lonely cards, never more than 6.
- Icon: one Lucide icon on the blush `tint` tile. The link names the destination ("See the audit"), not "Learn more".
- The whole card is not a link; only the text link is (better for keyboards and screen readers).
- Only the audit card may show a price ("$750"). Workshops and builds say "quoted from your roadmap" (positioning).
