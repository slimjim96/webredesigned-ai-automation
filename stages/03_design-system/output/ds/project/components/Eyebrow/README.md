# Eyebrow

A small mono label above a heading (`th-eyebrow`) or a bordered tag for a vertical or a place (`th-tag`).

## Use
- Eyebrow: one per heading block, above the H1 or H2, naming who or what the section is for ("For HVAC, plumbing & electrical"). Written in sentence case in the HTML; the component sets capitals.
- The ember dot in front is the only place `accent` appears in running UI.
- Tags: verticals and service areas on cards and the about page. Plain text, never links.

## Don't
- Don't use an eyebrow as a section number ("01"). Numbers belong only to `Steps`.
- Don't stack two eyebrows or put one on every card.
