# CTABand

The closing band at the bottom of most pages, on `inverse` navy: a short H2, one line, and the primary button.

## Use
- Once per page, right above the footer. Same button label as the hero.
- Text uses `on-inverse` and `on-inverse-muted`; the focus ring switches to `on-inverse` here.
- The brick button sits on navy: its white label keeps 6.3:1.
