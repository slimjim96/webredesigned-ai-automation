# SectionHeading

The opening of every section: optional eyebrow, an H2 (`text-h2`), and up to two sentences in `text-lede` with `ink-muted`.

## Use
- The H2 is a plain statement a skimmer could act on. Sentence case, no ending colon.
- Keep the block within 46rem; it never centers on desktop (left-aligned reads faster).
- `th-section-head` sets `space-6` below itself before the section's content.
