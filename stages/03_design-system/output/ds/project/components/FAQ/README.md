# FAQ

Questions and answers built on native `<details>`/`<summary>`: keyboard and screen-reader support come free, no script.

## Use
- 4 to 8 real questions owners ask on calls. Questions in their words; answers in two or three sentences.
- The first item may start `open`.
- Answers never promise outcomes we can't back (`_shared/rules.md` #1, #2). Mark open wording with `TODO:` until the owner confirms, as in this preview.
