# PriceCard

The audit offer: name, fixed price, what's included, the credit note, and the primary button.

## Use
- One per page, only for the audit. It is the only public price on the site (positioning: workshops and builds are "quoted from your roadmap").
- The button books the free call, not the audit. The call sells the audit.
- The included list uses `sage` checks; the credit note sits on `tint`.
- Price in `text-data`-style tabular numerals via `th-price__amount` (serif, so the number reads as a headline).

## Don't
- Don't add a struck-through "regular price", a countdown, or "most popular" ribbons.
