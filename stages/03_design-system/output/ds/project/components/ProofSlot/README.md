# ProofSlot

Where a testimonial, case result, or client logo will go, and the visible frame that holds its place until real proof exists.

## Use
- Until there is real, permitted proof, render `th-proof-needed` with the literal text `[[PROOF NEEDED]]` and a note of what proof belongs there. It is meant to look like a red flag: `07_launch` blocks while any remain (`_shared/rules.md` #2).
- With real proof: `th-quote` with the client's own words, their name, business and town. Nothing paraphrased, no stock headshots.
- The second item in this preview shows the layout only and says so.

## Don't
- Don't fill the slot with invented quotes, "Client name" placeholders that look real, or logos of companies that aren't clients.
